A 1024×1024 procedural space-art entry rendered from pure Python stdlib (`math`, `struct`, `zlib`) depicting a giant cosmic eye whose pupil is a total solar eclipse, with a retro rocket streaking straight into the eclipse and pixel-art `DON'T BLINK` lettering.

## Run

```bash
python3 draw.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
